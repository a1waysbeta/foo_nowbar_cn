一个为 foobar2000 设计的 “正在播放” 控制面板组件，同时支持默认界面 (Default UI) 和分栏界面 (Columns UI)。

<img width="1434" height="108" alt="nowbar" src="https://github.com/user-attachments/assets/bd1a04b9-9a9b-49ca-85c6-7e6bd7f722ee" />


### 核心功能
- **双界面支持**：在默认界面 (DUI) 和分栏界面 (CUI) 中均可无缝使用。
- **专辑封面显示**：显示专辑封面，支持直角/圆角切换，可添加边距。
- **在线封面获取**：当本地/内嵌封面不可用时，通过 [foo_artwork](https://github.com/jame25/foo_artwork) 从在线来源获取封面。
- **曲目信息显示**：最多支持 3 行可自定义的显示区域，支持自定义标题格式（默认：第1行标题，第2行艺术家，第3行可选格式或等级星标）；支持 `%playback_time%`、`%bitrate%`（VBR）及外部流媒体元数据的实时动态更新
- **选择模式**：可在“优先当前播放模式”（显示当前播放内容，停止时回退到选中曲目）和“跟随选择模式”（始终跟随播放列表中选中的项目）之间切换
- **高 DPI 适配**：在高 DPI 显示屏上自动缩放，并支持自适应尺寸与空间压缩

### 播放控制
- **播放/暂停**：中央播放按钮，用于切换播放状态。
- **停止**：可选的停止按钮（默认隐藏）- 停止播放。
- **当前音轨结束后停止**：可选的切换按钮（默认隐藏）- 在当前曲目播放完后停止；激活时显示强调色。
- **上一首/下一首**：在曲目间导航。
- **乱序播放**：切换乱序模式，并伴有视觉指示（激活时高亮；与迷你播放器双向同步）
- **重复播放**：循环切换重复模式：关闭 → 全部 → 单曲（激活时高亮；与迷你播放器双向同步）
- **进度条**：用于在曲目内跳转的交互式进度条。
  - 可选择胶囊形或矩形样式。
  - 显示已播放和剩余时间。
  - 鼠标悬停时显示光标位置的时间戳提示。
- **频谱模式下**：顶部边缘显示细进度条替代进度条，悬停时放大并显示时间戳提示。

### 音量控制
- **音量滑块**：点击或拖拽调节音量（采用感知响度映射，与 foobar2000 默认曲线一致）。
- **音量数字**：可选择在音量滑块或图标旁内联显示音量数值（静音时显示 0，范围为 1–100）；继承第二字体与颜色，替代悬停提示。
- **静音切换与记忆**：点击音量图标可切换静音/取消静音；取消静音时恢复之前的精确音量。
- **独立显示控制**：音量图标与音量条可独立开关（隐藏音量条时图标靠右对齐，并回收面板宽度）。
- **鼠标滚轮支持**：在面板上滚动滚轮即可调节音量。

### 特殊按钮
- **心形喜爱按钮**：点击可将当前曲目标记为“喜爱”。
  - 可配置的标签：`%FEEDBACK%`、`%2003_LOVED%`、`%LFM_LOVED%`、`%SMP_LOVED%` 或 `%MOOD%`。
  - 已标记时显示为红色，未标记时为灰色
  - 可在参数选项中隐藏
- **曲目评级星标**：交互式五星评级控件
  - 点击任意星标（1–5）可设定评级；再次点击当前激活的星标可清除评级（设为未评级 / `<未设置>`）
  - 通过上下文菜单与 [foo_playcount](https://www.foobar2000.org/components/view/foo_playcount) 集成
  - 灵活放置：可置于面板中央（播放控制行）或第 3 行（曲目信息区域）
  - 可在参数选项中隐藏
- **迷你播放器启动**：快速启动或显示迷你播放器的快捷按钮。
  - 需要 [foo_traycontrols](https://github.com/jame25/foo_traycontrols) 插件。
  - 默认隐藏。
- **功能聚合按钮**：包含自动播放列表查询和播放选项的快捷菜单。
  - 自动播放列表查询：从未播放、近5天播放、未评级、评级为 3-5/4/5、我的收藏（标记喜爱的曲目）、近2周添加、相同艺术家/标题。
  - **无限播放**：切换以在播放列表结束时自动添加相似曲目（基于媒体库的流派匹配）。
  - **播放预览**：子菜单，可设置在每首曲目的部分播放后自动跳过（关闭 / 35% / 50% / 60秒）。
  - **跳过低等级音轨**：子菜单，可直接切换并设置评级阈值（关闭 / 1 星 / ≤ 2 星 / ≤ 3 星）
  - **选择模式**：子菜单，可在“优先当前播放模式”与“跟随选择模式”之间切换
  - **设置**：快速链接以打开 Now Bar(播放控制面板) 设置页面。
- **最多 12 个自定义按钮**：完全可配置的操作按钮。
  - **按钮 1-6**：显示在面板上，通过设置页面配置。
  - **按钮 7-12**：隐藏，仅限键盘快捷键，通过配置文件配置。
  - 支持操作：打开 URL、[运行可执行文件](#highlight-word1)、执行 foobar2000 菜单命令（[主菜单或上下文菜单](#highlight-word2)）、打开文件夹、**输出设备**（点击后弹出菜单，列出所有音频输出设备，供切换当前输出）。
  - **3D 按钮样式**：为按钮添加立体凸起效果，带渐变和阴影，按下时有触感动画，默认启用。
  - **状态反馈**：当命令处于选中/激活状态时（例如切换命令），Foobar2k 操作按钮会显示强调色。
  - 自定义图标字符：支持 Unicode 符号（直接[输入字符或使用 U+XXXX 格式](#highlight-word3)），可选择自定义字体，图标大小百分比可调（50%–120%，默认 80%）。
  - 每个按钮可自定义悬停提示文本。
  - 自适应布局：高度较大时为双行（按钮 1-3, 4-6），高度较小时为单行。
  - 播放期间可自动隐藏（可选，带 300ms 平滑淡入淡出动画）。
  - URL/可执行文件操作使用所选曲目（而非正在播放的曲目）进行标题格式化。
  - 配置档案：可保存/加载按钮设置（新建 / 重命名 / 删除 / 导出 / 导入）。
  - 配置文件位置：`<foobar2000_profile>\foo_nowbar_data\custom_buttons.conf`（支持 `action = output_device`）

### 可视化模式
- **频谱**：叠加于播放按钮下方的全宽频谱分析器。
  - 可配置条形宽度（细 / 正常 / 宽）、高度（低：面板高度的20% / 正常：33% / 高：50%）和样式（条形 / 曲线 / 多米诺）。
  - **颜色模式**：自适应（从专辑封面主色采样，并进行 HSL 对比度归一化；无封面时回退到主题强调色）、纯色（自定义颜色）、渐变（自定义双色垂直渐变）、频率（内置频谱颜色）。
  - **不透明度滑块**：不透明度可在 0% 至 100% 之间调节（默认：75%）。
  - **平滑悬停淡出**：鼠标悬停在播放控制区域时，频谱条通过指数缓动平滑变暗，以便清晰显示按钮。
  - **播放时间显示**：可切换右上角已播放/总时间显示（显示 / 隐藏）。
  - 顶部边缘以细进度条替代进度条；悬停时放大，并在顶层显示时间戳提示，支持跳转定位。
  - 默认 30 FPS，可选 60 FPS 模式。
- **波形进度条**：采用 SoundCloud 风格预计算波形，取代原来的进度条。
  - **波形样式**：样式 1（离散垂直条状）与样式 2（连续双色居中包络，外缘为主强调色，核心色调更亮，静音部分显示基线）。
  - **波形宽度**：细（1px）、宽（2px）和宽（4K）（3px）密度选项（仅限样式 1）。
  - **扫光揭示动画**：切换曲目时从左至右扫光揭示（缓存曲目约 250ms，未缓存曲目随音频解码实时渐进呈现）。
  - 基于 RMS 计算，区分已播放/未播放颜色。
  - 波形数据跨会话缓存到磁盘（`wavecache.db`），支持 CUE 及子曲目。
  - 支持完整的跳转功能，悬停时显示时间提示。

### 主题与外观
- **主题模式**：
  - **自动**：自动跟随 foobar2000 的主题。
  - **深色**：强制使用深色模式。
  - **浅色**：强制使用浅色模式。
  - **自定义**：与 DUI 或 CUI 配色方案同步。
- **背景样式**：
  - **纯色**：标准的纯色背景。
  - **专辑封面颜色**：从专辑封面的主色中提取的动态渐变。
  - **模糊专辑封面**：将专辑封面模糊作为背景。
- **进度/音量条样式**：胶囊形或矩形。
- **进度条显示**：支持显示或完全隐藏进度条/波形图/频谱。
- **进度条长度模式**：
  - **固定模式**（默认）：进度条从左侧喜爱按钮延伸到右侧功能聚合按钮，长度固定不变。
  - **缩放模式**：进度条随面板宽度动态调整，向两侧空白区域延伸（占用两侧可用空隙的70%）。
- **进度条水平位置**：微调滑块（-100 至 +100 像素偏移），用于调整进度条的水平对齐。
- **音量控制显示**：可独立显示或完全隐藏音量图标与音量条。
- **音量数字**：切换音量数值显示（隐藏 / 显示）。
- **播放图标样式**：样式1（可切换正常风格：强调色圆圈，深色图标或反相风格：强调色圆圈，白色图标） / 样式 2 （矩形轮廓、无强调色圆圈） / 样式3（实心矩形、无强调色圆圈）。
- **悬停圆形背景**：按钮上可选的悬停效果。
- **悬停放大效果**：播放控制按钮在悬停时放大 15%。
- **自定义字体**：可为左侧信息区域第一、二、三行及时间显示选择自定义字体（支持颜色、下划线等格式）。
- **10 种自定义颜色**：按钮强调色、播放/暂停强调色、进度条强调色、音量条强调色、按钮悬停颜色、频谱颜色（含主色与次色渐变样本）、波形已播放/未播放颜色、进度条轨道色、音量条轨道色（每种颜色均可独立切换使用自定义颜色或主题派生颜色）。
- **平滑动画**：可切换的动画过渡效果（默认关闭以提升性能）。
  - 启用时：自定义按钮自动隐藏淡入淡出、背景切换淡入淡出。
  - 禁用时：即时切换，性能更佳。
- **专辑封面**：可切换专辑封面的可见性；可为专辑封面设置可选的边距。
- **在线封面**：当本地封面不可用时，从在线来源获取封面（需安装 [foo_artwork](https://github.com/jame25/foo_artwork) 插件）。

### 播放功能
- **选择模式**：可在“优先当前播放模式”（显示当前正在播放的内容，停止时回退到选中项）与“跟随选择模式”（曲目信息、封面、评级星标及喜爱图标始终跟随当前播放列表或媒体库中的选中项）之间切换。
- **跳过低等级音轨**：播放时自动跳过低等级的曲目（可配置阈值 1-3 星；需安装 foo_playcount 插件）。连续跳过 10 首曲目后暂停该功能，强制播放下一首，防止卡死；可在参数选项或功能聚合按钮菜单中切换。
- **无限播放**：当播放列表结束时，自动从媒体库中添加流派匹配的曲目（一次添加 15 首）。
- **播放预览**：快速浏览时，在每首曲目的部分播放后自动跳过（关闭 / 35% / 50% / 60秒）。

## 安装方法

1. **安装版 foobar2000**（已关联文件格式）：双击 `foo_nowbar*.fb2k-component` 文件安装<br>
   **便携版 foobar2000**：参数选项 → 组件 → 点击“安装” → 选择 `foo_nowbar*.fb2k-component` 文件 → 确定<br>
   
   **Releases 页面附件说明：**<br>
   - `foo_nowbar*.fb2k-component`：英文版<br>
   - `foo_nowbar-zh-CN*.fb2k-component`：中文版
   
2. 重启 foobar2000。
3. 添加面板：
   - **默认界面 (DUI)**：视图 → 布局 → 启用布局编辑模式 → 添加面板 → "播放控制面板"。
   - **分栏界面 (CUI)**：在您的布局中添加 "播放控制面板"。

### 自定义按钮选项卡

#### 配置档案
- **配置名称**：在已保存的按钮配置之间选择。
- **[...] 菜单**：新建、重命名、删除、导出、导入配置档案的选项。

#### 按钮配置
配置最多 6 个可见的自定义按钮（按钮 7-12 仅可通过配置文件配置）：
- **无**：按钮禁用。
- **打开链接**：在默认浏览器中打开一个 URL（支持标题格式化，使用所选曲目）。
- <a name="highlight-word1"></a>**运行程序**：启动一个外部程序（支持标题格式化，使用所选曲目，例如：路径输入 `D:\foobar2000\Spek\spek.exe`）。
- <a name="highlight-word2"></a>**Foobar2k 操作**：执行 foobar2000 菜单命令（例如：路径输入 `视图/ESLyric/桌面歌词/显示` 或上下文菜单 `文件操作/删除文件`）；当命令处于激活状态时显示强调色。
- **打开所在文件夹**：打开当前所选曲目所在的文件夹。
- **输出设备**：点击后弹出菜单，列出所有可用音频输出设备（ASIO、WASAPI、DirectSound、Null Output 等），可直接切换 foobar2000 的输出设备（无需填写路径）。

每个按钮还支持以下设置：
- **字体**：可从预设字体列表中选择（`Segoe UI`、`Segoe MDL2 Assets`、`Segoe Fluent Icons`、`Segoe UI Symbol`、`Material Icons Outlined`、`Material Icons`、`Wingdings`、`Webdings`），也可直接输入任意已安装的字体名称。
- <a name="highlight-word3"></a>**自定义图标**：支持 Unicode 符号，可直接输入字符或使用 U+XXXX 格式，比如字体选择 `Segoe UI`，字符处直接粘贴 `🎶`，或字体选择 `Segoe Fluent Icons`，字符处输入 `U+E8D6`。
- **图标大小**：可调整图标字符的百分比大小（预设：50%、60%、70%、80%、90%、100%、120%；默认：80%）。
- **提示文本**：悬停时显示的自定义文本（默认显示为 “按钮 #N”）。
- 当自定义图标缺失时，自动回退显示带数字的方形图标。

### 字体和颜色选项卡

#### 字体
- **左侧第一、二、三行**：左侧信息区域字体（支持颜色、下划线等格式）。
- **时间**：已播放/剩余时间的字体。

#### 颜色
每种颜色都有一个复选框：未勾选时使用来自 DUI/CUI 的主题颜色，勾选时使用自定义颜色。

| 颜色 | 默认（主题） | 描述 |
|-------|----------------|-------------|
| 按钮强调色 | DUI 高亮 / CUI 高亮 | 随机、重复等按钮的激活状态 |
| 播放/暂停按钮强调色 | DUI 高亮 / CUI 高亮 | 播放按钮的背景圆圈 |
| 进度条强调色 | DUI 高亮 / CUI 高亮 | 进度条填充色 |
| 进度条轨道色 | 主题派生 | 进度条未填充部分 |
| 按钮悬停色 | DUI 选定 / CUI 选定 | 按钮悬停圆圈 |
| 频谱颜色 | 自适应 / 纯色 / 渐变 / 频率 | 可视化条的颜色；包含颜色模式下拉菜单、不透明度滑块（0–100%）以及渐变模式下的双色样本 |
| 波形强调色 | DUI 高亮 / CUI 高亮 | 波形中已播放的部分 |
| 波形轨道色 | DUI 文字 / CUI 文本 | 波形中未播放的部分 |
| 音量条强调色 | DUI 高亮 / CUI 高亮 | 音量条填充色 |
| 音量条轨道色 | 主题派生 | 音量条未填充部分 |

### 键盘快捷键
所有 12 个自定义按钮的操作都可以通过键盘快捷键触发：

1. 转到 **参数设置 → 快捷键**。
2. 在 **文件 → 播放控制面板** 下查找命令：
   - `自定义按钮 1` 至 `自定义按钮 12`
3. 为相应按钮的操作分配任意键盘快捷键。
